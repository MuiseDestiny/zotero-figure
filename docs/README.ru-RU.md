# Zotero Figure

Локальное извлечение рисунков, таблиц и формул из PDF в Zotero.

[English](../README.md) | [简体中文](README.zh-CN.md) | [Italiano](README.it-IT.md) | [Русский](README.ru-RU.md) | [日本語](README.ja-JP.md) | [Español](README.es-ES.md)

Zotero Figure локально читает PDF-вложения с помощью MuPDF WASM, находит рисунки, таблицы, отдельные формулы, подписи и примечания к таблицам с помощью DocLayout-YOLO, а затем показывает извлеченные изображения на отдельной панели окна чтения PDF. Для анализа не требуется открытый Reader, а PDF не отправляется во внешние сервисы.

> Модель может ошибаться. Сообщайте о сбоях плагина, проблемах установки и воспроизводимых ошибках интеграции; точность распознавания в основном определяется самой моделью.

## Возможности

- Локальное распознавание рисунков, таблиц и отдельных формул.
- Ближайшее примечание к таблице включается в ее фрагмент и подпись.
- Прямое чтение вложения в Worker MuPDF WASM, извлечение числа страниц и текста, создание изображений 640 px для распознавания и прямой рендеринг PNG высокого разрешения по координатам PDF. Боковая панель и будущая пакетная обработка используют общие локальные результаты.
- Оптимизированная модель Q8 включена в XPI: установленная копия проверяется по точному размеру и SHA-256, затем проверенные байты передаются в Worker и перед инференсом еще раз проверяются по SHA-256.
- Индекс результатов каждого вложения сохраняется в JSON, а извлеченные изображения — в PNG в каталоге данных Zotero.
- Безопасный повторный анализ с заменой локальных результатов по страницам или добавлением только недостающих.
- Анализ можно отменить; отмена завершает затронутые Worker инференса, которые будут заново созданы для последующих задач. Размер отрисовки для распознавания остается равным 640 пикселям. Каждый результат вне кэша отрисовывается прямо из прямоугольника PDF: целевая длинная сторона 2400 px, до 6x и 8 мегапикселей, без полноразмерного холста страницы.
- Страницы без извлекаемого текста также передаются детектору, а не пропускаются. Для страниц с текстом используются более строгие полные обозначения рисунков и таблиц на английском, китайском, итальянском и русском языках.
- Значок Zotero Figure в левой боковой области служит единственной основной точкой входа; плагин не добавляет кнопку на верхнюю панель окна чтения.
- Адаптивные карточки упорядочены сначала по странице PDF, затем по визуальному положению сверху вниз и слева направо. Фильтры **Все**, **Рисунки**, **Таблицы** и **Формулы** показывают число результатов. Локальные PNG загружаются отложенно рядом с видимой областью через отзываемые Blob URL, не более чем по три изображения одновременно.
- Длинные подписи по умолчанию свернуты; нажмите на подпись, чтобы развернуть или свернуть ее.
- Панель действий для запуска или отмены анализа, добавления всех результатов в заметку, обновления и очистки локальных результатов. При очистке панель сразу становится пустой, JSON и PNG удаляются в фоне, а существующие зеркальные аннотации Zotero не затрагиваются.
- Ход анализа в Reader отображается прямо в боковой панели: процентная шкала и локализованный текст текущего этапа заменяют отдельное окно прогресса.
- При установленном Zotero PDF Translate подписи можно перевести кнопкой языка и вернуть к оригиналу повторным нажатием. Успешные переводы кэшируются локально отдельно для каждого целевого языка и используются повторно.
- Существующие локальные результаты можно в любой момент преобразовать в зеркала аннотаций Zotero кнопкой на панели действий.
- Меню каждой карточки позволяет скопировать, сохранить или закрепить изображение, изменить подпись, исправить область на перетаскиваемом превью всей страницы, перейти к странице, добавить изображение в заметку или удалить его. Исправленный фрагмент заново отрисовывается в высоком разрешении и сохраняется после повторного анализа.
- Необязательное зеркалирование результатов в стандартные графические аннотации Zotero с тегами `Figure N`, `Table N` или `Formula N` и подписями в комментариях. По умолчанию параметр выключен.
- В настройках оставлены только обслуживание встроенной модели и необязательная синхронизация аннотаций; пояснение о синхронизации доступно через компактный значок справки со знаком вопроса.
- Создание заметок Zotero с настоящими встроенными PNG-вложениями для одной карточки или всех результатов. Изображение в заметке остается ссылкой на соответствующий фрагмент исходного PDF даже без зеркальной аннотации.
- Интерфейс на английском, упрощенном китайском, итальянском и русском языках.

## Требования

- Только Zotero 9.
- XPI из [последнего выпуска](https://github.com/MuiseDestiny/zotero-figure/releases/latest).

Текущая локальная схема больше не требует Java и `pdffigures2.jar`.

## Установка и настройка

1. Загрузите `zotero-figure.xpi` из последнего выпуска.
2. В Zotero откройте `Инструменты > Плагины`, выберите установку из файла и укажите XPI.
3. Откройте PDF, выберите значок Zotero Figure в левой боковой области и запустите анализ. Встроенная модель будет подготовлена и проверена автоматически, отдельная загрузка не нужна.

## Встроенная модель

Zotero Figure включает только модель Q8 с удаленными неиспользуемыми выходами `optimized-q8-6c25a56c`, размером 19 505 323 байта, SHA-256 `6c25a56caf796a074e26def15eea9018686836155fd9e15e5e0950e9c08a4cac`. Она полностью сохраняет тензор `output0`, используемый плагином, и удаляет семь неиспользуемых выходных ветвей. XPI копирует ее в `zotero-figure/models/` каталога данных Zotero и проверяет копию перед анализом.

После получения XPI доступ к GitHub или Hugging Face для модели не требуется. Публикуйте один и тот же XPI в GitHub Releases и на региональном зеркале с одинаковым SHA-256. См. [правила распространения](MODEL_DISTRIBUTION.md).

## Использование

1. Откройте PDF-вложение в окне чтения Zotero.
2. Нажмите значок Zotero Figure в левой боковой области. На верхней панели окна чтения кнопки Zotero Figure нет.
3. Выберите **Анализировать рисунки, таблицы и формулы** на панели действий и дождитесь завершения отрисовки страниц и распознавания.
4. Переключайтесь между **Все**, **Рисунки**, **Таблицы** и **Формулы**. В меню карточки можно скопировать, сохранить, закрепить или исправить изображение, изменить подпись, перейти к странице, добавить его в заметку или удалить.
5. Если установлен Zotero PDF Translate, нажмите кнопку языка для перевода подписей; повторное нажатие возвращает оригинал.
6. При необходимости используйте действия **Добавить все результаты в заметку**, **Обновить рисунки и таблицы** и **Очистить локальные результаты**. Очистка удаляет только локальные JSON и PNG плагина, но не существующие зеркальные аннотации Zotero.
7. Чтобы дополнительно создать синхронизируемые графические аннотации, включите в настройках **После анализа также синхронизировать результаты с аннотациями изображений Zotero**. По умолчанию параметр выключен.
8. Для пакетной обработки выберите один или несколько элементов библиотеки либо PDF-вложений, откройте контекстное меню и используйте **PDF Figure > Анализировать рисунки, таблицы и формулы**, **Анализировать рисунки, таблицы и формулы и добавить в заметку** или **Анализировать рисунки, таблицы и формулы и создать аннотации**. PDF обрабатываются последовательно, открывать вкладку Reader не требуется.

Панель всегда читает собственное локальное хранилище плагина. Для каждого PDF-вложения метаданные сохраняются в `zotero-figure/results/<libraryID>/<attachmentKey>/manifest.json` в каталоге данных Zotero, а PNG — в соседнем каталоге `images/`. Манифест схемы v5 сохраняет ручные исправления подписей и областей, переводы по целевым языкам и версионированные идентификаторы кэша изображений. Исправленные подписи и области сохраняются после повторного анализа, поскольку обнаруженные значения хранятся отдельно для сопоставления кэша; при редактировании подписи устаревший кэш перевода этого результата удаляется. Повторный анализ использует PNG только тогда, когда совпадают отпечаток исходного файла вложения (размер и время изменения, а если они недоступны — версия объекта Zotero), версия анализа, хэш модели, версия превью, отпечаток результата и отпечаток текущей области, а сам PNG по-прежнему существует. Манифест, кэши переводов и PNG не используют Zotero Sync. При включении синхронизации аннотаций создается дополнительная копия в виде стандартных аннотаций для синхронизации и совместимости с другими плагинами, но источник данных панели не меняется. В заметки добавляются встроенные изображения-вложения, а не ссылки на локальные пути PNG; даже без зеркальных аннотаций нажатие на изображение открывает соответствующий фрагмент исходного PDF.

Подготовка MuPDF, модели и Worker планируется на время простоя окна чтения. Первый анализ все еще может быть медленнее, если начинается до завершения подготовки. Скорость зависит от PDF, процессора и доступной памяти.

Во время анализа одновременно планируется не более трех страниц. Ограниченные этапы допускают до двух страниц в распознавании, один запрос рендеринга MuPDF, один этап областей высокого разрешения и одну операцию сохранения. Длинная сторона изображения для распознавания равна 640 px. Результаты вне кэша по одному отрисовываются прямо из прямоугольников PDF: целевая длинная сторона 2400 px, до 6x и 8 мегапикселей. Два постоянных Worker ONNX работают параллельно по одному потоку инференса каждый; отмена завершает затронутые Worker. Это дублирует сессию Q8, но устраняет прежний полноразмерный холст страницы. См. [бюджет производительности](PERFORMANCE.md).

## Конфиденциальность

Разбор и рендеринг PDF выполняются встроенным MuPDF WASM; распознавание выполняется внутри Zotero с помощью Transformers.js и ONNX Runtime Web. Страницы PDF не отправляются во внешний сервис, а модель не загружается во время работы.

Локальные JSON- и PNG-файлы результатов остаются в каталоге данных Zotero. Они могут покинуть устройство только при отдельном резервном копировании или синхронизации этого каталога пользователем либо при включении синхронизации аннотаций для создания дополнительной копии.

## Разработка

Требуется Node.js 20.10 или новее.

```bash
npm install
npm run check
npm run build
```

`npm run check` запускает проверку форматирования, ESLint, TypeScript, тесты и проверку сборки. `npm run build` создает `build/zotero-figure.xpi`. Перед `npm start` скопируйте `scripts/zotero-cmd-default.json` в `scripts/zotero-cmd.json` и укажите локальные пути Zotero.

## Архитектура

| Путь                  | Назначение                                                   |
| --------------------- | ------------------------------------------------------------ |
| `src/domain`          | Чистые типы и алгоритмы сопоставления макета                 |
| `src/features`        | Интерфейс чтения, пакетные действия и настройки              |
| `src/services`        | Анализ, очередь распознавания, обрезка и локальное хранилище |
| `src/platform/zotero` | Типизированная граница с API Zotero                          |
| `addon`               | Bootstrap, переводы, Worker и метаданные модели              |
| `scripts`, `tests`    | Воспроизводимая сборка и автоматические проверки             |

Доменная логика не должна зависеть от глобальных объектов Zotero. Доступ к закрытым API следует изолировать в адаптерах платформы.
