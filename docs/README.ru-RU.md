# Zotero Figure

Извлечение рисунков, таблиц и формул из PDF в Zotero.

[English](../README.md) | [简体中文](README.zh-CN.md) | [Italiano](README.it-IT.md) | [Русский](README.ru-RU.md) | [日本語](README.ja-JP.md) | [Español](README.es-ES.md)

Zotero Figure находит в PDF рисунки, таблицы, отдельные формулы, подписи и примечания к таблицам. Чтение, рендеринг и определение макета PDF выполняются локально с помощью модели, встроенной в плагин.

## Возможности

- Локальный анализ PDF без отправки страниц и загрузки модели во время работы.
- Просмотр результатов на отдельной панели Reader с фильтрами по типу и ходом анализа.
- Копирование, сохранение и закрепление изображений; изменение подписей и областей; переход к странице PDF; добавление в заметку и удаление результата.
- Просмотр результатов из нескольких документов в **Библиотеке иллюстраций PDF** с фильтрами по библиотеке, документу, году, категории, типу и подписи.
- Пакетный анализ выбранных элементов библиотеки или PDF-вложений с необязательным созданием заметок или аннотаций Zotero.
- Перевод подписей при установленном Zotero PDF Translate.
- Необязательное распознавание LaTeX через SiliconFlow `Qwen/Qwen3.6-35B-A3B`, локальная отрисовка с помощью KaTeX, копирование, повторное распознавание и редактирование в Monaco Zotero.
- Создание заметок Zotero со встроенными PNG, ведущими к исходному PDF.
- Необязательное дублирование локальных результатов в графические аннотации Zotero для синхронизации и совместимости.
- Интерфейс на английском, упрощенном китайском, итальянском и русском языках.

## Требования

- Zotero 9.
- XPI Zotero Figure из [последнего выпуска](https://github.com/MuiseDestiny/zotero-figure/releases/latest).
- Только для OCR формул: сеть и ключ API SiliconFlow.

Java и `pdffigures2.jar` не требуются.

## Установка

1. Загрузите `zotero-figure.xpi` из последнего выпуска.
2. В Zotero откройте `Инструменты > Плагины`, выберите установку из файла и укажите XPI.
3. Перезапустите Zotero, если появится запрос.

## Точки входа

- **PDF Reader:** Откройте PDF, выберите значок Zotero Figure в левой боковой области и запустите анализ рисунков, таблиц и формул.
- **Библиотека иллюстраций:** Откройте `Инструменты > Библиотека иллюстраций PDF` для просмотра результатов из разных документов. Выбор карточки открывает исходный PDF.
- **Пакетная обработка:** Выберите элементы библиотеки или PDF-вложения, щелкните правой кнопкой мыши и откройте `PDF Figure >`, чтобы выполнить анализ, добавить результаты в заметки или создать аннотации.
- **Настройки:** Откройте панель настроек PDF Figure для управления встроенной моделью, синхронизацией аннотаций и OCR формул. Команда **Преобразовать существующие формулы** распознает формулы без кэша во всех библиотеках.

## Конфиденциальность

Разбор, рендеринг, определение макета PDF и хранение результатов выполняются на компьютере. Локальные результаты не используют Zotero Sync, пока не включено дублирование в аннотации.

OCR формул необязателен. Проверка ключа API отправляет в SiliconFlow только текстовый запрос. Распознавание отправляет PNG-фрагменты формул, но не целые страницы PDF; ключ хранится в локальных настройках Zotero. Использование SiliconFlow может тарифицироваться.
