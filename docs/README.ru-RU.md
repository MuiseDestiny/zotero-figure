# Zotero Figure

Локальное извлечение рисунков и таблиц из PDF в Zotero.

[English](../README.md) | [简体中文](README.zh-CN.md) | [Italiano](README.it-IT.md) | [Русский](README.ru-RU.md) | [日本語](README.ja-JP.md) | [Español](README.es-ES.md)

Zotero Figure локально отрисовывает страницы PDF, находит рисунки, таблицы и подписи с помощью DocLayout-YOLO, а затем показывает извлеченные изображения на отдельной панели окна чтения PDF. PDF и данные для распознавания не отправляются во внешние сервисы.

> Модель может ошибаться. Сообщайте о сбоях плагина, проблемах установки и воспроизводимых ошибках интеграции; точность распознавания в основном определяется самой моделью.

## Возможности

- Локальное распознавание рисунков и таблиц.
- Оптимизированная модель Q8 включена в XPI: установленная копия проверяется по точному размеру и SHA-256, затем проверенные байты передаются в Worker и перед инференсом еще раз проверяются по SHA-256.
- Индекс результатов каждого вложения сохраняется в JSON, а извлеченные изображения — в PNG в каталоге данных Zotero.
- Безопасный повторный анализ с заменой локальных результатов по страницам или добавлением только недостающих.
- Анализ можно отменить; отмена во время инференса завершает активный Worker, который будет заново создан для последующих задач. Размер отрисовки для распознавания остается равным 640 пикселям. Каждая страница с результатами отрисовывается один раз с ограничениями до 4x, 12 мегапикселей и 8192 пикселей на сторону, после чего все найденные прямоугольники вырезаются из этого единственного изображения страницы.
- Страницы без извлекаемого текста также передаются детектору, а не пропускаются. Для страниц с текстом используются более строгие полные обозначения рисунков и таблиц на английском, китайском, итальянском и русском языках.
- Значок Zotero Figure в левой боковой области служит единственной основной точкой входа; плагин не добавляет кнопку на верхнюю панель окна чтения.
- Адаптивные карточки с фильтрами в порядке **Все**, **Рисунки**, **Таблицы**; каждый фильтр показывает число результатов. Локальные PNG загружаются отложенно рядом с видимой областью через отзываемые Blob URL, не более чем по три изображения одновременно.
- Длинные подписи по умолчанию свернуты; нажмите на подпись, чтобы развернуть или свернуть ее.
- Панель действий для запуска или отмены анализа, добавления всех результатов в заметку, обновления и очистки локальных результатов. При очистке панель сразу становится пустой, JSON и PNG удаляются в фоне, а существующие зеркальные аннотации Zotero не затрагиваются.
- При установленном Zotero PDF Translate подписи можно перевести кнопкой языка и вернуть к оригиналу повторным нажатием. Успешные переводы кэшируются локально отдельно для каждого целевого языка и используются повторно.
- Существующие локальные результаты можно в любой момент преобразовать в зеркала аннотаций Zotero кнопкой на панели действий.
- Меню каждой карточки позволяет скопировать или сохранить изображение, перейти к странице, добавить изображение в заметку или удалить его.
- Необязательное зеркалирование результатов в стандартные графические аннотации Zotero с тегами `Figure N` или `Table N` и подписями в комментариях. По умолчанию параметр выключен.
- Создание заметок Zotero с настоящими встроенными PNG-вложениями для одной карточки или всех результатов. Изображение в заметке остается ссылкой на соответствующий фрагмент исходного PDF даже без зеркальной аннотации.
- Интерфейс на английском, упрощенном китайском, итальянском и русском языках.

## Требования

- Только Zotero 9.
- XPI из [последнего выпуска](https://github.com/MuiseDestiny/zotero-figure/releases/latest).

Текущая локальная схема больше не требует Java и `pdffigures2.jar`.

## Установка и настройка

1. Загрузите `zotero-figure.xpi` из последнего выпуска.
2. В Zotero откройте `Инструменты > Плагины`, выберите установку из файла и укажите XPI.
3. Откройте PDF, выберите значок Zotero Figure в левой боковой области и запустите анализ. Встроенная модель будет подготовлена и проверена автоматически, отдельная загрузка не нужна.

## Встроенная модель

Zotero Figure включает только оптимизированную модель Q8 `optimized-q8-d5d1e664`, размером 20 552 482 байта, SHA-256 `d5d1e664fbe639e716be7011aa7493b40f4ab498374b2157988c2ea41bf70daf`. XPI копирует ее в `zotero-figure/models/` каталога данных Zotero и проверяет копию перед анализом.

После получения XPI доступ к GitHub или Hugging Face для модели не требуется. Публикуйте один и тот же XPI в GitHub Releases и на региональном зеркале с одинаковым SHA-256. См. [правила распространения](MODEL_DISTRIBUTION.md).

## Использование

1. Откройте PDF-вложение в окне чтения Zotero.
2. Нажмите значок Zotero Figure в левой боковой области. На верхней панели окна чтения кнопки Zotero Figure нет.
3. Выберите **Анализировать рисунки и таблицы** на панели действий и дождитесь завершения отрисовки страниц и распознавания.
4. Переключайтесь между **Все**, **Рисунки** и **Таблицы**. В меню карточки можно скопировать или сохранить изображение, перейти к странице, добавить его в заметку или удалить.
5. Если установлен Zotero PDF Translate, нажмите кнопку языка для перевода подписей; повторное нажатие возвращает оригинал.
6. При необходимости используйте действия **Добавить все результаты в заметку**, **Обновить рисунки и таблицы** и **Очистить локальные результаты**. Очистка удаляет только локальные JSON и PNG плагина, но не существующие зеркальные аннотации Zotero.
7. Чтобы дополнительно создать синхронизируемые графические аннотации, включите в настройках **После анализа также синхронизировать результаты с аннотациями изображений Zotero**. По умолчанию параметр выключен.

Панель всегда читает собственное локальное хранилище плагина. Для каждого PDF-вложения метаданные сохраняются в `zotero-figure/results/<libraryID>/<attachmentKey>/manifest.json` в каталоге данных Zotero, а PNG — в соседнем каталоге `images/`. Манифест схемы v3 сохраняет переводы подписей по целевым языкам и версионированные идентификаторы кэша изображений. Повторный анализ использует PNG только тогда, когда совпадают отпечаток исходного файла вложения (размер и время изменения, а если они недоступны — версия объекта Zotero), версия анализа, хэш модели, версия превью и отпечаток результата, а сам PNG по-прежнему существует. Манифест, кэши переводов и PNG не используют Zotero Sync. При включении синхронизации аннотаций создается дополнительная копия в виде стандартных аннотаций для синхронизации и совместимости с другими плагинами, но источник данных панели не меняется. В заметки добавляются встроенные изображения-вложения, а не ссылки на локальные пути PNG; даже без зеркальных аннотаций нажатие на изображение открывает соответствующий фрагмент исходного PDF.

Подготовка модели и Worker планируется на время простоя окна чтения. Первый анализ все еще может быть медленнее, если начинается до завершения подготовки. Скорость зависит от PDF, процессора и доступной памяти.

Во время анализа одновременно планируется не более трех страниц. Отдельные ограниченные этапы допускают до двух страниц в распознавании, одну отрисовку страницы для распознавания, одну страницу высококачественного превью и одну операцию сохранения. Страницы для распознавания отрисовываются с размером 640 пикселей. Для страницы с результатами, отсутствующей в кэше, PDF отрисовывается один раз с ограничениями до 4x, 12 мегапикселей или 8192 пикселей на сторону, а все прямоугольники результатов вырезаются из одного изображения. Один Worker инференса используется повторно и может задействовать до четырех потоков WASM, сохраняя логические ресурсы для Zotero; отмена активного инференса завершает Worker, чтобы он не продолжал занимать процессор. Один Worker также исключает дублирование сессий модели.

## Конфиденциальность

Распознавание выполняется внутри Zotero с помощью Transformers.js и ONNX Runtime Web. Страницы PDF не отправляются во внешний сервис, а модель не загружается во время работы.

Локальные JSON- и PNG-файлы результатов остаются в каталоге данных Zotero. Они могут покинуть устройство только при отдельном резервном копировании или синхронизации этого каталога пользователем либо при включении синхронизации аннотаций для создания дополнительной копии.

## Разработка

Требуется Node.js 20.10 или новее.

```bash
npm install
npm run check
npm run build
```

`npm run check` запускает проверку форматирования, ESLint, TypeScript, тесты и проверку сборки. `npm run build` создает `build/zotero-figure.xpi`. Перед `npm start` скопируйте `scripts/zotero-cmd-default.json` в `scripts/zotero-cmd.json` и укажите локальные пути Zotero.

## Архитектура

| Путь                  | Назначение                                                   |
| --------------------- | ------------------------------------------------------------ |
| `src/domain`          | Чистые типы и алгоритмы сопоставления макета                 |
| `src/features`        | Интерфейс окна чтения и настройки                            |
| `src/services`        | Анализ, очередь распознавания, обрезка и локальное хранилище |
| `src/platform/zotero` | Типизированная граница с API Zotero                          |
| `addon`               | Bootstrap, переводы, Worker и метаданные модели              |
| `scripts`, `tests`    | Воспроизводимая сборка и автоматические проверки             |

Доменная логика не должна зависеть от глобальных объектов Zotero. Доступ к закрытым API следует изолировать в адаптерах платформы.
